# Predicting Digital Experiment Success Using A/B Testing Metrics

## Overview
This project explores whether machine learning models can predict the likelihood of digital experiment success using common A/B testing and engagement metrics.

The project combines experimentation analytics, predictive modeling, feature evaluation, and business interpretation to analyze relationships between experiment characteristics and successful outcomes.

## Problem
Digital experimentation programs generate large amounts of behavioral and performance data, but identifying which experiments are likely to succeed before launch remains difficult. This project investigates whether historical experimentation metrics can be used to predict experiment outcomes using supervised machine learning techniques.

## Dataset
The analysis uses a synthetic experimentation dataset designed to simulate realistic experimentation metrics including:
- conversion rates
- lift
- p-values
- engagement metrics
- session behavior
- experiment traffic characteristics

## Methods
The notebook includes:
- exploratory data analysis (EDA)
- feature engineering
- logistic regression
- random forest classification
- feature importance analysis
- model evaluation and comparison

## Tools and Technologies
- Python
- pandas
- scikit-learn
- matplotlib
- Jupyter Notebook

## Key Findings
The project demonstrated that experimentation metrics can provide predictive signals related to experiment success, although model performance varied depending on feature selection and class balance considerations.

The analysis also highlighted risks associated with over-reliance on narrow engagement metrics and synthetic data limitations.
