# Telco Customer Churn Prediction

## Overview
This project analyzes customer churn behavior within a telecommunications dataset using supervised machine learning techniques. The goal is to identify patterns associated with customer attrition and evaluate predictive model performance.

## Problem
Customer churn can significantly impact recurring revenue and long-term customer retention. Organizations often use predictive analytics to identify customers at risk of leaving so retention strategies can be applied proactively.

## Dataset
The project uses the Telco Customer Churn dataset containing:
- customer demographics
- contract information
- internet service details
- billing behavior
- tenure
- churn outcomes

## Methods
The analysis includes:
- data cleaning and preprocessing
- feature engineering
- train/test splitting
- feature scaling
- logistic regression
- random forest classification
- confusion matrix analysis
- ROC-AUC evaluation

## Tools and Technologies
- Python
- pandas
- scikit-learn
- matplotlib
- seaborn
- Jupyter Notebook

## Key Findings
The logistic regression model achieved approximately 80% accuracy with strong ROC-AUC performance. Key predictive features included tenure, monthly charges, internet service type, and contract length.

The project also compared model performance between logistic regression and random forest approaches to evaluate tradeoffs between interpretability and predictive performance.
