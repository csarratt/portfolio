# IMDb Film Success Data Mining

## Overview
This project explores relationships between movie characteristics and commercial or audience success using data mining and machine learning techniques applied to IMDb film data.

## Problem
Film performance can be influenced by a combination of factors including genre, ratings, runtime, release timing, and audience reception. This project investigates which variables appear most associated with successful films.

## Dataset
The analysis uses movie-related data including:
- IMDb ratings
- genres
- runtime
- release year
- popularity indicators
- additional film metadata

## Methods
The notebook includes:
- exploratory data analysis
- correlation analysis
- feature exploration
- visualization
- predictive modeling
- random forest analysis

## Tools and Technologies
- Python
- pandas
- matplotlib
- scikit-learn
- Jupyter Notebook

## Key Findings
The analysis identified several variables associated with stronger film performance and demonstrated how machine learning models can identify patterns across entertainment datasets.

The project also highlighted the importance of feature selection and interpretation when working with mixed categorical and numerical entertainment data.
