About

I am currently completing a Master of Science in Data Science and have experience in data analysis, A/B testing, and machine learning. This portfolio highlights projects that connect technical work with real-world business decisions.

Work / Projects

The projects below represent a mix of academic data science work and professional experience. They highlight predictive modeling, experimentation, data preparation, visualization, and applied artificial intelligence.

A/B Testing and Experimentation Framework

This project represents real-world experimentation work focused on evaluating product and experience changes through controlled A/B testing. Experiments were designed with control and variant groups, clear success metrics, and analysis of lift, p-values, sample size, and statistical significance.

Tools: Optimizely, Adobe Analytics, statistical analysis

Outcome: Supported data-driven recommendations for production changes and improved confidence in digital experiment reporting.

Sales Forecasting Pipeline

This project focused on forecasting future sales using historical retail data. The work included data cleaning, time-based feature engineering, regression modeling, and model evaluation using RMSE.

Tools: Python, pandas, scikit-learn, Jupyter Notebook

Outcome: Built a forecasting workflow that connected raw sales data to practical planning and demand insights.

Generative AI Invoice Extraction System

This project explored how generative AI can extract structured information from unstructured invoice documents. The workflow used prompt design, JSON formatting, and output review to convert document text into usable fields.

Tools: OpenAI API, Python, JSON parsing, prompt engineering

Outcome: Demonstrated how GenAI can support document processing and reduce manual review in structured data workflows.
