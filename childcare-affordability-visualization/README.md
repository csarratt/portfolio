# Childcare Affordability Visualization Dashboard

## Overview
This project analyzes childcare affordability across the United States using county-level and state-level cost and income data. The project focuses on communicating affordability burdens through visual storytelling, dashboard design, and executive-style reporting.

## Problem
Childcare affordability varies significantly across regions, but statewide averages can often hide important county-level differences. The goal of this project was to identify affordability patterns and present them using multiple visualization approaches for decision-support purposes.

## Dataset
The analysis uses county-level childcare pricing and household income data, including:
- infant center-based childcare costs
- toddler center-based childcare costs
- family childcare costs
- median household income
- county and state geographic identifiers

## Methods
The project includes:
- affordability ratio calculations
- state-level aggregation
- county-level comparison analysis
- dashboard KPI generation
- visualization design
- infographic support analysis

## Visualizations Included
- affordability ratio distributions
- top burdened states
- income versus childcare cost analysis
- infant versus toddler affordability comparison
- county-level variation analysis
- state tile map dashboard
- KPI dashboard cards

## Tools and Technologies
- Python
- pandas
- matplotlib
- PowerPoint
- Jupyter Notebook

## Key Findings
The analysis demonstrated substantial regional variation in childcare affordability burdens across both states and counties. Statewide averages often masked significant county-level differences, reinforcing the importance of localized affordability analysis.

The project also demonstrated how dashboards and infographic-driven storytelling can support executive communication and policy discussion.
