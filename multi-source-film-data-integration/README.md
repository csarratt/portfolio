# Multi-Source Film Data Integration

## Overview
This project combines and analyzes film-related data from multiple structured and semi-structured sources to create a unified analytical dataset for downstream exploration and reporting.

## Problem
Data projects frequently require integrating information from multiple systems with inconsistent formats, schemas, and field structures. This project demonstrates workflows for cleaning, merging, and standardizing multi-source datasets.

## Data Sources
The project integrates information from multiple sources including:
- IMDb datasets
- Wikipedia film information
- OMDb API data
- SQLite database workflows

## Methods
The notebook includes:
- data extraction
- data cleaning
- schema alignment
- SQL workflows
- dataset merging
- derived feature creation
- exploratory analysis

## Tools and Technologies
- Python
- pandas
- SQLite
- APIs
- Jupyter Notebook

## Key Findings
The project demonstrated how integrated datasets can support richer downstream analysis than isolated data sources alone. It also highlighted common challenges associated with inconsistent schemas and incomplete source data.
